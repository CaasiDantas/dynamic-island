# Política de segurança

## Versões com suporte

Somente a versão mais recente publicada em [Releases](https://github.com/CaasiDantas/dynamic-island/releases/latest) recebe correções de segurança. O app se atualiza sozinho, então manter as atualizações ativas é a forma mais simples de ficar protegido.

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use o [relato privado de vulnerabilidades](https://github.com/CaasiDantas/dynamic-island/security/advisories/new) do GitHub e inclua:

- a versão afetada;
- uma descrição do problema e do impacto;
- os passos para reproduzir.

O recebimento é confirmado em até 7 dias, e você será informado do andamento até a correção ser publicada.

## Atualizações assinadas

Cada atualização é assinada com uma chave privada do projeto. O app verifica a assinatura antes de instalar e recusa qualquer pacote que não corresponda à chave pública embutida nele.
